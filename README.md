# SoR 字典認證練功房

SoR 拼讀字典「字典認證」互動學習單：初級 120 題、中級 120 題、高級 100 題，每個單字配 SoR專利注音積木與真人音檔。

網址：https://lilinwang0928-cyber.github.io/dictionary/

## 安裝成 App
- iPhone／iPad：用 Safari 打開網址 → 分享 → 加入主畫面
- Android：用 Chrome 打開網址 → 右上角 ⋮ → 加到主畫面／安裝應用程式
- 電腦：用 Chrome 或 Edge 打開網址 → 網址列右邊的「安裝」圖示

## 功能
- 📅 練習日程：一級兩個月、5 天一單元，排到月底 23:59 截止
- 試題總覽（含一次唸完）、逐題練習、★ 重點複習（含備份匯出匯入）
- 模擬錄音、模擬錄影（背板、去背、定位框、全螢幕練習）
- 正式錄影（去背背景、美顏、預覽位置、回放與下載）
- 認證須知、延伸學習、使用說明

認證辦法以官方公告為準：https://milinguall.com/news_2024.aspx?id=347
